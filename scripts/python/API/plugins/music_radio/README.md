# MusicRadio

Scaffold plugin for DCS Olympus plugin manager.

## Status

Structure initialized. Runtime playback logic intentionally left empty.

## Config

- `music_folder`: Folder path containing music files to be used by this plugin.
- `music_frequency_hz`: Radio frequency in Hertz where music should be played.
- `music_modulation`: Radio modulation mode (e.g. 0 = AM, 1 = FM).
