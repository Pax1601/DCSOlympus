# UnitRadioEmbark

Scaffold plugin for DCS Olympus plugin manager.

## Status

Structure initialized. Runtime logic intentionally left empty.

## Config

- `blue_embark_frequency_hz`: Blue coalition embark radio frequency in Hertz.
- `red_embark_frequency_hz`: Red coalition embark radio frequency in Hertz.
- `blue_modulation`: Blue coalition modulation type (e.g. 0 = AM, 1 = FM).
- `red_modulation`: Red coalition modulation type (e.g. 0 = AM, 1 = FM).
- `blue_encryption`: Blue coalition encryption mode (0 = none).
- `red_encryption`: Red coalition encryption mode (0 = none).
