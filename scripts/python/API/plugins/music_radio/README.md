# MusicRadio

DCS Olympus Music Radio plugin.

## Config

- `music_folder`: Folder path containing music files to be used by this plugin. Only mp3 and wav file supporters. To enforce order start files with a number.
- `music_frequency_hz`: Radio frequency in Hertz where music should be played.
- `music_modulation`: Radio modulation mode (e.g. 0 = AM, 1 = FM).
